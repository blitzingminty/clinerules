# Examples

This directory provides copy-pasteable `.clinerules/` setups for common project types.

## Available examples

- [Python (Standard tier)](./python/README.md) - Standard documentation, Git, and coding rules for professional Python projects.
- [TypeScript (Standard tier)](./typescript/README.md) - Standard documentation, Git, and coding rules for professional TypeScript projects.

## How to use any example

1. Open the example that matches your project type.
2. Copy that example's `.clinerules/` directory into the root of your own project.
3. Tell Cline to follow the rules in your project's `.clinerules/` directory.
4. Customize the copied files for your team and domain.
